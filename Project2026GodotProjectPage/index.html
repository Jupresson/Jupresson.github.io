Project Development Story

Overview & Teamwork
2026 Godot Project is a first-person platformer set in the Backrooms, built solo in Godot 4. I am building the whole thing myself: the level tools, the movement, and the game state handling underneath it.

Show more

Game Concept & Design
The player walks, runs, jumps, and slides through liminal Backrooms rooms and corridors. There is no climbing. Right now I am focused on getting that base movement to feel right before I build more levels or systems on top of it.

My Role & Challenges
I build levels in TrenchBroom, using custom objects for spawn points and death areas, then import them into Godot 4. I handle game states cleanly, and map textures load and display correctly across levels.

A Note on the Screenshot
The screenshot above is from the current build. I originally optimized the camera effects with FSR upscaling, then replaced that with a shader-based approach that stretches the view slightly. It looks almost as good and runs far better.

Project Outcome & Lessons Learned
Development is on hold at the prototype stage: I joined a new team project building an AI camera quality-detection system and shifted my focus there. Features like the enemy AI, chase and darkness effects, checkpoints, and a sound manager are planned for when I pick this back up, not built yet.
