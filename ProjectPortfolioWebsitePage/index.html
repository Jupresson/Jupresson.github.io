Portfolio Website

Static website made with Astro

A personal portfolio built to showcase my projects and skills. I designed, coded, and refined it from scratch across three versions to get it right.

Project Development Story

Overview & Teamwork
This portfolio's main purpose is to collect and showcase my projects, serve as proof of my work, and present my experience clearly to anyone reading it. This was a fully solo project. I designed, built, and completed every part of it myself.

Show more

Concept & Design
The idea was to create a simple static website that presents my projects clearly. I built the first version from scratch using HTML and CSS in Visual Studio Code, but the codebase became too messy to scale. I then rebuilt it with a cleaner template, but the colors and layout were too heavy on the eyes. The current version is built with Astro, which lets me create reusable components like the shared header, and is fully responsive across many screen sizes.

My Role & Challenges
One of my main goals was full mobile support, which required the layout to scale cleanly across all screen sizes. Managing three versions of the site over time also taught me a lot about writing maintainable and scalable code from the start, something I learned the hard way by rebuilding it twice.

Project Outcome & Lessons Learned
Overall, building the portfolio was a rewarding experience. Working with Astro made development much smoother thanks to its component system. I also got more comfortable using AI tools to speed up development, particularly to look up syntax and HTML tags fast instead of digging through documentation by hand, and to help clean up and sharpen my written English.
